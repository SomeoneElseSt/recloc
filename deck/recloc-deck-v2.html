03  KEY INSIGHT

The phone already watches your location. We just never send it anywhere.

iOS evaluates geofences on-device — the same mechanism behind Uber's airport ping. A server never learns where you are; it only needs to hand the phone a task.

01

Address stays on the VM, briefly

Validated before sending, so the phone can resolve it.

02

Coordinates never travel

The fence lives in iOS. No GPS fix ever reaches a server.

03

The agent never sees the place

Saved addresses are redacted from the model.
